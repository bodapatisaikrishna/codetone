# Changelog

## 1.3.1 — 2026-11-16

- Comprehensive testing suite: restored and expanded mechanical tests (80+ checks in `tests/test_skill.py`) and full behavioral evaluation suite (`evals/`).
- GitHub Actions CI workflow (`.github/workflows/check.yml`) running automated spec validation and tests on every push and pull request.
- Added `requirements-dev.txt` for standardized developer setup.
- Standardized `Source:` attribution line in `tcl.md` for 100% uniformity across all 24 language references.
- Re-verified all 28 external documentation URLs with automated health checks.
- Added full community standards and developer documentation (`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, PR and issue templates).

## 1.3.0 — 2026-11-16

- Renamed the project to **CodeTone** (skill name `codetone`). It still
  condenses Google's style guides, credited in `NOTICE.md`; not affiliated with
  Google.

## 1.2.0 — 2026-11-16

- Fact-checked all 24 rule sheets against the original guides and fixed about
  100 wrong or overstated rules (e.g. Python and C++ TODO format, JavaScript
  operator line-breaks, XML key-value pairs, C# `ref`/containers, Objective-C
  `nullptr`).
- Tools lines now separate tools the guide names from common extras.
- All Markdown wrapped at 80 columns with `mdformat`, following our own Markdown
  sheet.
- Added `tests/` (58 mechanical tests) and a CI workflow.

## 1.1.0 — 2026-11-16

- Adapters for Cursor, GitHub Copilot, Windsurf, `AGENTS.md`-based tools and
  chat apps, generated by `scripts/build_adapters.py`.
- Spec fields (`license`, `metadata`) added to `SKILL.md`.

## 1.0.0 — 2026-11-16

- First release: `SKILL.md` router plus 24 condensed rule sheets.
